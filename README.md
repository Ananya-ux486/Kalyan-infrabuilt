# Kalyan Infrabuilt — Single Landing Page

This package is a fresh, single-page landing experience for Kalyan Infrabuilt / Shiv Ganga Estate.

## What changed
- One page only — no separate Home/About/Projects/Contact HTML pages.
- Premium, classy real-estate visual direction using the existing Kalyan logo and supplied project assets.
- Hero area inspired by the provided property-search reference image, with working Buy / Rent / Projects / Commercial / Dealers tabs.
- Working locality search interaction and browser-location button.
- Project details and amenity cards open useful detail modals.
- Six supplied project videos are arranged in a proper slider with thumbnails, arrows, progress indicator, autoplay-on-selection and large video view.
- Gallery is interactive with an image lightbox.
- Location section uses the supplied Greater Kanpur map and reference visuals.
- Enquiry form gives a proper on-page confirmation and is clearly marked for final CRM/email connection.
- Smooth navigation, active section highlighting, scroll-reveal animation, hover interactions, responsive mobile menu and progress bar.
- Existing supplied images, video files, posters and PDFs are retained in `assets/`.

## Run
1. Extract the ZIP.
2. Open the `kalyan-infrabuilt` folder (the folder containing `index.html`) in VS Code.
3. Use Live Server, or open `index.html` directly in a browser.
4. No Node.js/build step is required.

## Important before launch
The supplied project material intentionally does not provide verified sales phone/email details. Do not invent them. Connect the enquiry form to the client's verified email/CRM/backend and add verified phone, exact office/site address, pricing, plot sizes, RERA/approval information and any other legal/commercial claims only after client confirmation.

The regional infrastructure section is context only; it does not promise appreciation, travel times or future development.
